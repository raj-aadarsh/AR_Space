# AR_Space — Personal Portfolio

> Live site: [raj-aadarsh.github.io/AR_Space](https://raj-aadarsh.github.io/AR_Space)

A personal portfolio built to reflect the kind of work I do — precise, performant, and a little obsessive about the details. Every section has a unique 3D particle object that assembles as you scroll, built from scratch using React Three Fiber and GSAP.

---

## Tech stack

| Layer | Tools |
|---|---|
| Framework | React 18 + Vite |
| 3D / WebGL | Three.js, React Three Fiber, Drei |
| Animation | GSAP 3, ScrollTrigger |
| Smooth scroll | Lenis |
| Deployment | GitHub Pages via GitHub Actions |

Tuned to be responsive across different devices and screen orientations.
